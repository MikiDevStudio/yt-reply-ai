Write to me. It arrives as an email, and a person answers it.

There is one person behind this extension, so the answer comes from him and it comes in a day or two rather than in an hour. Everything is worth sending: a reply that came out wrong, a button that never appeared, a question about the trial, a request to delete your data.

What happened?

If it is a bug, the video it happened on and what you saw instead is enough — no logs, no screenshots required. Nothing is collected from your browser to go with it.

Where do I answer?

The address is used to reply to this message and nothing else — it is not added to any list, and there is no mailing to unsubscribe from. Details in the privacy policy.

No account, no captcha, no ticket number.

Sent. It is in the inbox.

The answer comes to the address you gave, usually within a day or two. There is no ticket number to quote and nothing else you have to do — if it turns out to be a bug, you will also get the version number it was fixed in.

Nothing was stored about you beyond the message and that address.

Open an issue instead

A bug or a feature request is better in the open: it gets a number, other people can add to it, and the fix arrives with a version you can check. The code is public and so is the tracker.
